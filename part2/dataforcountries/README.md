# Data for Countries

A React app that lets you search countries, view country details, and see current weather for the selected country.

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the app:
   ```bash
   export VITE_OPENWEATHERMAP_API_KEY=key && npm run dev
   ```

Replace `key` with your OpenWeatherMap API key.
